
# 💻 LeetCode Solutions

Welcome to my LeetCode solutions repository! This repository automatically tracks, syncs, and backs up my coding journey and algorithmic problem-solving progress using the LeetSync browser extension.

## 🛠️ Repository Structure

The solutions are automatically structured by the extension as follows:
```text
.
├── 📂 Problem-Name/
│   ├── README.md           # Problem description and constraints
│   └── Solution.ext        # Solution code (e.g., .py, .cpp, .c, .java)
└── README.md               # Main repository overview
```

## 🚀 How It Works

1. **Solve:** I work through data structures and algorithms problems directly on LeetCode.
2. **Submit:** Once a solution passes all test cases and is marked as **Accepted**.
3. **Sync:** The LeetSync extension automatically commits and pushes the code to this repository within seconds.
